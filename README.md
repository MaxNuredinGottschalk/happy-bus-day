# 해피버스데이 (HAPPY BUS DAY) — 웹 앱 베이스

D-Tech 융합기반 이노베이션 디자인 세미나 II, 2조. Vite + React + TypeScript.

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 빌드가 통과하는지 확인
```

화면 오른쪽의 **데모 직원 패널**에서 방문 상태를 바꾸면 어르신 화면이 따라 바뀝니다. 탭 두 개를 열어 두면 둘이 같이 움직입니다. 화면 주소는 `#/e1` \~ `#/e10` 으로 바로 열 수 있습니다.

## 폴더와 역할 분담 (충돌을 피하려고 폴더로 나눕니다)

|폴더|내용|담당 제안|
|-|-|-|
|`src/elderly/`|어르신 화면 E1–E10|막스 (기본 틀)|
|`src/guardian/`|보호자 화면 G1–G7 (비어 있음)|성규 / 수연|
|`src/state/`|공유 데이터·상태|막스 (바꿀 때 먼저 이야기하기)|
|`src/styles.css`|색·글자 등 디자인 값|같이|

화면 하나 = 파일 하나입니다. 새 화면은 `src/guardian/G1Home.tsx` 처럼 만들고 `src/App.tsx` 에 연결합니다. 상태는 `useVisit()` 로 읽고 `setVisit()` 로 바꿉니다.

## 시안과 다르게 한 점 (확인 필요)

* 시안 E5–E10 하단에는 "도움 요청"만 있었지만, 팀 규칙(모든 화면 하단 좌 "소리로 듣기" / 우 "도움 요청")에 맞춰 모두에 넣었습니다.
* E9: 주차 수정 사항("보호자에게 이미 알림" 삭제)에 따라 알림 완료 문구를 뺐습니다.
* E10: 아무것도 미리 선택하지 않습니다. 고르지 않으면 공유하지 않습니다.
* 아직 안 정해진 것은 시안처럼 `\[ ]` 자리표시로 남겼습니다 (고객센터 번호, 보호자 번호, 약도, 준비물 목록).
* 소리 읽기는 브라우저 음성(`speechSynthesis`, ko-KR)입니다. 기기에 한국어 음성이 없으면 안 나올 수 있습니다.

## GitHub 처음 쓰는 분께 (간단 가이드)

1. 저장소 주소 복사 → `git clone <주소>` → `cd` 로 폴더 안으로 → `npm install`
2. 내 작업용 가지 만들기: `git checkout -b user/g1-home`  (main 에서 직접 작업하지 않기)
3. 수정 후: `git add .` → `git commit -m "G1 화면 추가"` → `git push -u origin suyeon/g1-home`
4. GitHub 웹에서 **Compare \& pull request** 를 눌러 올리면, 막스가 확인 후 합칩니다.
5. 작업 시작 전에는 항상 `git checkout main \&\& git pull` 로 최신을 받습니다.

처음에는 GitHub Desktop 앱을 써도 됩니다 (같은 순서를 버튼으로 할 수 있습니다).
